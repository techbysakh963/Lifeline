# Security

Lifeline runs commands on computers and handles AI accounts, so security reports matter a lot.

**Please report security problems privately:** [open a private report](https://github.com/techbysakh963/Lifeline/security/advisories/new) (GitHub › Security › Report a vulnerability). Don't open a public issue for them.

Useful to include: the Lifeline version, what an attacker could do, and the steps to show it. You'll get an answer, and a fixed release with credit if you'd like it.

In scope, for example: a way around the approval card or the blocked-command list, secrets reaching the AI or the logs, another app on the phone reaching Lifeline's setup link or SSH, or the PC-side setup script doing more than it says.
